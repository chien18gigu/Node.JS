# Bài tập 01 - Quản lý thông tin sinh viên bằng JavaScript ES6

## Mô tả yêu cầu
- Sử dụng `class` và `constructor` để biểu diễn đối tượng Sinh viên (gồm mã, họ tên, tuổi, điểm).
- Khởi tạo danh sách gồm 5 sinh viên.
- Sử dụng arrow function (`=>`) kết hợp phương thức `.filter()` để lọc ra các sinh viên có điểm $\ge 5.0$.
- In kết quả ra màn hình console.

## Các bước thực hiện
1. Tạo thư mục cấu trúc dự án: `NodeJS/Bai03/Bt01/`
2. Tạo tập tin mã nguồn `bai01.js` chứa logic chương trình.
3. Chạy lệnh thực thi trên Terminal:
   ```bash
   node bai01.js
