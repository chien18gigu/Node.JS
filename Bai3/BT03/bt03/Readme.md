# Bài tập 03 - Thao tác tập tin bằng File System (`fs` module)

## Mô tả yêu cầu
- Sử dụng module `fs` trong Node.js để tương tác với hệ thống tập tin.
- **Tạo tập tin**: Khởi tạo tập tin `thongtin.txt` chứa thông tin họ tên và mã sinh viên.
- **Đọc tập tin**: Đọc và hiển thị nội dung file ra Terminal lần đầu.
- **Ghi nối tập tin**: Sử dụng phương thức `appendFile()` để bổ sung thông tin lớp học vào cuối tập tin.
- **Kiểm tra cập nhật**: Đọc lại tập tin để xác minh dữ liệu đã được cập nhật thành công.

## Các bước thực hiện
1. Tạo thư mục cấu trúc dự án: `NodeJS/Bai03/Bt03/`
2. Tạo tập tin mã nguồn `bai03.js` chứa các hàm xử lý file đồng bộ/bất đồng bộ của `fs`.
3. Chạy lệnh thực thi trên Terminal:
   ```bash
   node bai03.js
